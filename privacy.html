Privacy Policy

Last updated: October 5, 2026

Overview

Codex YouTube Uploader is a personal utility used by its owner to upload videos to the owner's own YouTube channel using the YouTube Data API and Google OAuth.

Google user data

The application requests only the Google OAuth permissions necessary to upload videos to YouTube. Google user data obtained through those permissions is used solely to perform YouTube upload actions explicitly requested by the owner.

Storage

The application does not operate a public backend service. OAuth credentials and tokens used by the uploader are intended to be stored locally on the owner's device and are not intentionally transmitted to or stored on a separate application server.

Sharing

The application does not sell, rent, or share Google user data with third parties. Data is sent to Google/YouTube only as required to perform the requested YouTube API operation.

Retention and deletion

Locally stored OAuth tokens may be deleted by the owner at any time. The owner may also revoke the application's Google account access from their Google Account permissions page.

Security

OAuth client configuration and access tokens are kept out of public source repositories. Reasonable measures are used to prevent credentials from being published or disclosed.

Contact

For questions about this application or this policy, contact the project owner through the GitHub profile.
